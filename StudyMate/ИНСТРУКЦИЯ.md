  StudyMate: как выпускать и обновлять приложение

Свой сервер и GitHub Pages  не нужны . Используется бесплатный GitHub:
- он сам собирает и подписывает APK (на вашем компьютере ничего ставить не надо);
- он хранит готовый APK в разделе  Releases ;
- приложение при запуске проверяет там новую версию и предлагает обновиться.

Всё делается в браузере. Нужен только аккаунт GitHub.

---

   Часть 1. Один раз: настройка

    Шаг 1. Аккаунт и репозиторий
1. Зарегистрируйтесь на https://github.com/signup (если аккаунта нет).
2. Нажмите  +  справа вверху →  New repository .
3. Название: `studymate` (любое латиницей). Выберите  Public  (публичный, это обязательно: из закрытого репозитория приложение не сможет скачать обновление). Остальное не трогайте →  Create repository .

    Шаг 2. Загрузите проект
1. Распакуйте архив `StudyMate-project.zip` в папку.
2. На странице нового репозитория нажмите ссылку  uploading an existing file .
3. Перетащите в окно браузера  всё содержимое  распакованной папки: `app`, `.github`, `build.gradle.kts`, `settings.gradle.kts`, `gradle.properties`, `.gitignore`, `ИНСТРУКЦИЯ.md`. Перетаскивайте именно папки целиком.
4. Подождите, пока загрузится, внизу нажмите  Commit changes .

> Если папки `.github` не видно (на Windows/Mac скрытые папки могут не показываться), включите показ скрытых файлов. Или создайте файл вручную:  Add file → Create new file , в поле имени введите `.github/workflows/release.yml` (слэши создадут папки), вставьте туда содержимое файла `release.yml` из архива и нажмите Commit.

После загрузки в репозитории должны быть видны папки `.github` и `app`.

    Шаг 3. Ключ подписи
В архиве с ключами (`signing`) лежат:
- `studymate-release.jks` — ключ подписи приложения;
- `keystore.base64.txt` — тот же ключ в виде текста;
- `passwords.txt` — пароль.

 Сохраните папку `signing` в надёжном месте (облако, флешка) и никому не показывайте.  Если ключ потеряется, обновить уже установленное приложение будет невозможно: придётся ставить его заново с удалением старого. В репозиторий этот ключ загружать нельзя.

    Шаг 4. Передайте ключ GitHub (секреты)
1. В репозитории:  Settings  → слева  Secrets and variables  →  Actions .
2. Нажмите  New repository secret  и создайте два секрета:
   - Name: `KEYSTORE_BASE64`, Secret: весь текст из файла `keystore.base64.txt` (одной строкой, откройте блокнотом, Ctrl+A, Ctrl+C);
   - Name: `KEYSTORE_PASSWORD`, Secret: пароль из `passwords.txt` (то, что после `KEYSTORE_PASSWORD=`).

    Шаг 5. Первый выпуск
1. Вкладка  Actions . Если появилась кнопка  I understand my workflows, go ahead and enable them , нажмите её.
2. Слева выберите  Выпуск обновления  → справа  Run workflow .
3. В поле версии введите `1.0.0`, в «Что нового» — например `Первая версия` →  Run workflow .
4. Подождите 4–8 минут. Зелёная галочка = готово. Красный крестик = ошибка (см. «Если что-то пошло не так» ниже).
5. На главной странице репозитория справа появится  Releases  → откройте последний релиз → скачайте  StudyMate.apk .

    Шаг 6. Установка на телефон (первый раз)
Старая версия приложения подписана временным ключом, поэтому поверх неё новая не встанет.
1.  Сначала сохраните то, что нужно:  при удалении приложения все его данные (задачи, заметки, расписание) пропадают. Встроенного экспорта в приложении нет.
2. Удалите старый StudyMate.
3. Откройте на телефоне страницу релиза, скачайте `StudyMate.apk`, откройте файл. Android попросит разрешить установку из этого источника (браузера), разрешите.

Это нужно сделать  только один раз . Дальше все обновления ставятся поверх, данные сохраняются.

---

   Часть 2. Как выпустить обновление (каждый раз)

1.  Внесите изменения.  Весь интерфейс приложения находится в файле `app/src/main/assets/index.html`.
   - В репозитории откройте папку `app` → `src` → `main` → `assets`.
   - Нажмите  Add file → Upload files , перетащите свой новый `index.html` (с тем же именем) →  Commit changes . Он заменит старый.
2.  Запустите выпуск:  вкладка  Actions  →  Выпуск обновления  →  Run workflow .
   - Версия:  больше предыдущей : было `1.0.0`, пишите `1.0.1` (или `1.1.0`, `2.0.0`). Всегда три числа через точки.
   - «Что нового»: короткий текст, пользователи увидят его в окне обновления.
3. Через несколько минут релиз готов. Больше ничего делать не надо.

    Что увидят пользователи
При запуске приложение (не чаще раза в 6 часов) проверяет Releases. Если версия новее, появляется окно «Доступно обновление» с вашим текстом. Нажимают  Обновить , приложение скачивает файл, Android показывает стандартный экран установки. В шапке приложения также есть кнопка ↻ для ручной проверки.

При самом первом обновлении Android один раз попросит разрешить StudyMate устанавливать приложения. Нужно включить переключатель и вернуться назад.

---

   Важные правила
-  Версия всегда должна расти.  Нельзя выпустить `1.0.1` дважды: GitHub выдаст ошибку, что такой релиз уже есть. Исправление ошибок → `1.0.2`.
-  Репозиторий должен остаться публичным.  Это значит, что код приложения (`index.html`) виден всем.
-  Не удаляйте релизы.  Приложение берёт файлы из самого последнего.
-  Ключ подписи (`studymate-release.jks`) храните в безопасном месте.  Без него обновления невозможны.
- Нельзя менять секреты `KEYSTORE_*` на другой ключ: тогда Android откажется ставить обновление.

---

   Если что-то пошло не так
-  Красный крестик в Actions.  Откройте запись → нажмите на красный шаг → скопируйте текст ошибки и покажите мне, я исправлю.
-  «Не добавлены секреты».  Вернитесь к шагу 4: имена секретов должны совпадать буква в букву.
-  «Приложение не установлено» / «конфликт с существующим пакетом».  На телефоне осталась старая версия с другим ключом. Удалите её и поставьте заново (шаг 6).
-  Кнопка ↻ пишет «Не удалось проверить».  Проверьте интернет и что в репозитории есть хотя бы один релиз.

---

   Для разработчиков (необязательно)
- Исходники: `app/src/main/java/com/studymate/app/` (`MainActivity`, `AndroidBridge` — мост для `window.AndroidBridge`, `UpdateManager` — загрузчик обновлений).
- Адрес обновлений вычисляется из имени репозитория автоматически: `https://github.com/<владелец>/<репозиторий>/releases/latest/download/update.json`.
- В `update.json` лежат `versionCode`, `versionName`, `notes` и `sha256`. Приложение сверяет хеш скачанного APK.
- Код версии считается как `мажор*10000 + минор*100 + патч`.
- Локальная сборка: Android Studio, подпись из `keystore.properties` (`storeFile`, `storePassword`, `keyAlias`).
